# Stock Count Mismatch — handheld prototype

Interactive prototype for the Accellor UX assignment: a warehouse worker scans bin 14-C-03, counts 96 against a system quantity of 120, reports the mismatch to a supervisor and moves on to the next bin.

- `index.html` — the prototype, built on the exported screen PNGs (live at https://stockpilot-prototype.vercel.app)
- `Stock Count Prototype.html` — the same prototype as a single offline file with the screens embedded

Controls: yellow keys or Space to scan, type digits on the keyboard, Tab to switch fields, Enter to confirm. Tick "Unreadable label" to see the failed-scan path (check digits `47`).
